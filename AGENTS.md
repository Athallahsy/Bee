# AGENTS.md — Bee Story

## Deskripsi Project
3D scroll-driven storytelling website tentang lebah, terinspirasi struktur layout
dari drone.riotters.com (numbered section, big typography, stat callout, floating
annotation card) tapi dengan palette & tone yang beda (bukan tech/industrial, tapi
natural/botanical).

- Tailwind CSS 4

- @react-three/fiber ^9.7.0
- @react-three/drei ^10.7.8

## Known Issues / Fix yang JANGAN di-revert
1. **Material di Bee.jsx pakai `<meshStandardMaterial map={diffuseMap} />` manual**,
   BUKAN `material={materials.mtl_bee41}` bawaan gltfjsx. Ini disengaja — auto material
   dari gltfjsx kehilangan texture reference karena model source pakai
   `KHR_materials_pbrSpecularGlossiness` (legacy) yang gagal convert otomatis ke
   metallic-roughness. Kalau regenerate ulang dari gltfjsx, WAJIB reapply fix ini.
2. **`diffuseMap.flipY` harus TETAP default (true)** — JANGAN di-set `false`. Sempat
   di-set false dan menyebabkan UV ke-flip vertikal (area sayap salah sample ke area
   badan di texture atlas).
3. Model punya bone bernama `head_Jnt` (dan children: mandible, antenna, labrum) —
   dipakai nanti buat head-tracking mouse. Jangan rename node ini.
4. Model punya 3 animasi baked: `_bee_idle`, `_bee_hover`, `_bee_take_off_and_land`.
